# Configuration

Technical settings live in `.env`. Never commit this file.

| Variable | Purpose | Example |
| --- | --- | --- |
| `ADMIN_PASSWORD_SALT` | Hexadecimal salt generated by setup | secret |
| `ADMIN_PASSWORD_HASH` | scrypt hash of the initial password | secret |
| `PUBLIC_ORIGIN` | Allowed public origin | `https://tournaments.example.com` |
| `DATABASE_PATH` | SQLite path | `/data/tournament.sqlite` |
| `SITE_ADDRESS` | Domain or port served by Caddy | `tournaments.example.com` |
| `HOST` | Node server interface | `0.0.0.0` |
| `PORT` | Internal application port | `3001` |
| `TRUST_PROXY` | Trust headers from the configured proxy | `1` with Caddy |
| `NODE_ENV` | Enables secure cookies and production behavior | `production` |

Run `node scripts/setup.mjs` or `npm run setup:admin` to generate credentials. Do not write passwords or hashes by hand.

## Visible customization

Use **Administration → Tournament & rules** to configure language, identity, logo, poster, sport, terminology, currency, rules, contact details, and public links. Participant names, transfer details, and contact details are public.

For local assets, copy files into `public/` and save a path such as `/logo.png`. Remote assets must use HTTPS.
